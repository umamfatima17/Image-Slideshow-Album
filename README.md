# Photo Slideshow Album

A simple photo slideshow application built using Python, Tkinter, and Pillow.

## Features

- Display photos in a slideshow.
- Automatically change images every 2 seconds.
- Play and pause the slideshow.
- Navigate to the next and previous images.
- Simple graphical user interface.

## Technologies Used

- Python
- Tkinter
- Pillow (PIL)

## Requirements

- Python 3
- Pillow library

## Installation

Install Pillow using the following command:

```bash
python -m pip install Pillow
```

## How to Run

1. Clone or download this repository.
2. Update the image paths in `image_slideshow.py` to match the locations of your images.
3. Open a terminal in the project folder.
4. Run the application:

```bash
python image_slideshow.py
```

## Note

This application uses local image paths. Update the paths in the code to display your own photos.

## Learning Purpose

This project was created to practice Python basics, GUI development with Tkinter, image handling with Pillow, and event scheduling using `after()`.
